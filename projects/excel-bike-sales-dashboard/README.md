# Bike Sales Dashboard in Excel

## Overview
Created an interactive Excel dashboard to analyze customer demographics and bike purchasing behavior.

## Tools
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers

## Key Analysis
- Average income by gender and purchase status
- Bike purchases by age group
- Customer commute distance
- Interactive filtering by region, education, and marital status

## Skills
Excel • Data Cleaning • Pivot Tables • Dashboard Design • Data Visualization
