# Amazon Web Scraping with Python

## Overview
Built a Python web scraper to collect Amazon product details, track prices, store results in a CSV file, and send a price alert when the price drops below a specific value.

## Tools
- Python
- BeautifulSoup
- Requests
- Pandas
- CSV
- SMTP

## Key Tasks
- Extracted product title and price
- Cleaned the collected data
- Stored results in a CSV file
- Read the dataset using Pandas
- Created an automated price alert
