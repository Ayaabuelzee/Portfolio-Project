# Automotive Sales & Performance Dashboard in Excel

An interactive Excel dashboard designed to clean, analyze, and visualize sales data, providing insights into sales performance, customer behavior, and key business trends through dynamic KPIs and visualizations.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting

## Features
- Data Cleaning & Preparation
- Sales Trend Analysis
- Customer Insights
- Interactive Dashboard
- KPI Tracking
